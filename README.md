# Мини-Склад

Учебная конфигурация на платформе «1С:Предприятие». Работа выполнена в рамках первой недели курса КБ99 «1С Старт с нуля».

Автор: Казнодий Никита Андреевич.

## Возможности

- Ведение справочников «Товары», «Контрагенты» и «Склады».
- Оформление документов «Поступление» и «Реализация» с табличной частью «Товары».
- Автоматический расчёт суммы строки при изменении количества или цены в форме документа.
- Приход и расход товаров через регистр накопления «ОстаткиТоваров» в разрезе товара и склада.
- Доступ к объектам через подсистему «Мини-Склад».
- Поле «Комментарий» в документе «Поступление».

## Содержимое репозитория

```text
src/          Полная выгрузка конфигурации в XML, BSL и другие файлы
README.md     Описание проекта и порядок запуска
.gitignore    Правила исключения локальных и временных файлов
```

В каталоге `src` должен находиться файл `Configuration.xml` вместе с остальными файлами и каталогами выгрузки. Нельзя переносить только XML или BSL отдельно: для загрузки нужна полная выгрузка.

## Требования

- Платформа «1С:Предприятие» с Конфигуратором и тонким клиентом.
- Разработка и проверка выполнялись на платформе 8.5. Совместимость с другими версиями отдельно не проверялась.

## Как открыть конфигурацию

1. Скачать репозиторий через **Code → Download ZIP** и распаковать архив либо клонировать его через Git.
2. В окне запуска 1С создать новую файловую информационную базу без конфигурации. Использовать отдельную пустую базу, чтобы не затронуть имеющиеся данные.
3. Открыть базу в режиме **Конфигуратор** и выбрать **Конфигурация → Открыть конфигурацию**.
4. Выбрать команду загрузки конфигурации **из файлов**. В используемой версии она может называться **Загрузить конфигурацию из файлов** или **Загрузить файлы конфигурации**.
5. В окне загрузки выбрать **XML-файлы** и указать каталог `src`. Если диалог запрашивает файл, указать `src/Configuration.xml`.
6. Дождаться загрузки и выполнить **Конфигурация → Обновить конфигурацию базы данных** (F7). Просмотреть и подтвердить создание объектов.
7. Запустить **1С:Предприятие** и открыть подсистему «Мини-Склад».

Выгрузка содержит структуру и код конфигурации. Введённые ранее товары, контрагенты, склады и документы в неё не входят; после установки их нужно создать самостоятельно.

## Как проверить работу

1. Создать товар «Кукла», склад «Склад1» и контрагентов для поступления и реализации.
2. Создать и провести «Поступление» на 10 единиц товара на «Склад1».
3. Создать и провести «Реализацию» на 3 единицы того же товара с того же склада.
4. Открыть «Остатки товаров» и проверить записи: приход 10 и расход 3. Этот список показывает движения регистра, а не готовый остаток.
5. Изменить количество или цену строки документа и проверить автоматический пересчёт суммы после выхода из ячейки.

Итоговый остаток в этом примере составляет **7 единиц**. Для его просмотра можно выполнить следующий запрос в отдельной совместимой консоли запросов:

```bsl
ВЫБРАТЬ
    Остатки.Товар,
    Остатки.Склад,
    Остатки.КоличествоОстаток
ИЗ
    РегистрНакопления.ОстаткиТоваров.Остатки() КАК Остатки
```

Консоль запросов в состав проекта не входит. Если есть другие движения по этому товару и складу, результат будет учитывать их тоже.

## Ограничения

Это учебный проект первой недели, а не готовая система для рабочего учёта. Конфигурация создана самостоятельно и не находится на поддержке поставщика. В репозитории хранится выгрузка конфигурации в файлы, без файловой базы и резервных копий.
